## 🎮 游戏特色

### 核心玩法循环

1. **月初**：市政厅下达本月的「园林指标」
   - 产量型：收获指定数量的作物
   - 品质型：上交高品质作物
   - 多样性型：种植多种不同的花卉
   - 经济型：实现单日农场收入目标
   - 特殊型：培育稀有作物

2. **月中**：玩家规划土地、购买种子、种植、照料
   - 根据作物生长周期精准计算
   - 确保在月底前能收获

3. **月底**：系统结算
   - 达成指标：获得大量金币、钻石、稀有种子
   - 未达成：罚款并影响市政厅信誉度

### 游戏特色

- ✨ **14种作物**：从快速生长的小麦到传奇的樱花树苗
- 🏆 **信誉系统**：连续完成指标获得加成奖励
- 🌡️ **作物养护**：浇水、施肥影响产量和品质
- 🏗️ **设施建造**：温室、加工厂、智能规划屋等
- 📊 **智能规划**：系统自动计算并推荐最佳种植方案
- 🎯 **成就系统**：解锁称号和特殊奖励

## 🔑 核心功能

### 1. 作物收获日期计算（用户要求的核心功能）

```python
from glorias_magic_farm.core import can_harvest_before_deadline
from glorias_magic_farm.data import get_crop_info
from datetime import datetime

# 获取作物数据
crop_data = get_crop_info("番茄")

# 计划种植日期和截止日期
plant_date = datetime(2024, 5, 15)
deadline = datetime(2024, 5, 31)  # 月底

# 判断是否能在月底前收获
result = can_harvest_before_deadline(crop_data, plant_date, deadline)

print(f"能否在月底前收获: {result['can_harvest']}")
print(f"预计收获日期: {result['harvest_date']}")
print(f"时间余量: {result['days_margin']} 天")
```

### 2. 智能种植建议

游戏会根据当前日期和月底截止日期，自动分析所有作物，推荐最佳种植方案：

```python
game = GloriaMagicFarm()
game.show_planting_suggestions()
```

系统会考虑：
- 时间是否充足
- 投资回报率（ROI）
- 作物稀有度
- 综合推荐分数

### 3. 完整的农场经营

```python
# 创建游戏
game = GloriaMagicFarm(player_name="Gloria")

# 购买并种植
result = game.buy_and_plant_crop("小麦")

# 照料作物
game.water_all_crops()
game.fertilize_all_crops()

# 推进时间
game.advance_day()

# 收获并出售
harvest_results = game.harvest_all_and_sell()

# 查看状态
game.show_farm_status()
game.show_player_status()
game.show_target_progress()
```
